# Keyboard shortcuts

VisualCommit's keys are fixed: no setting changes them. The settings screen's
**Keyboard shortcuts** section lists them as on your system, and every menu, tooltip and the
command palette show an action's key beside it.

On macOS, Cmd mostly takes the place of Ctrl, and Option that of Alt; the tables give each key as
each system has it. Ctrl+Tab, for example, is Ctrl on every system. The text boxes' usual keys,
such as Ctrl+C (Cmd+C on macOS) to copy, are left out. What keys do in each part of the window, and
how to reach what has no key of its own, is in
[Keyboard and screen readers](../keyboard-and-screen-readers.md).

### App

| Action | Windows and Linux | macOS |
|---|---|---|
| Command palette | Ctrl+Shift+P | Cmd+Shift+P |
| Open settings… | Ctrl+, | Cmd+, |
| Show or hide the activity log | Ctrl+J | Cmd+J |
| Refresh | F5, Ctrl+R | Cmd+R, F5 |

### Tabs

| Action | Windows and Linux | macOS |
|---|---|---|
| New tab | Ctrl+T | Cmd+T |
| Close tab | Ctrl+W | Cmd+W |
| Next tab | Ctrl+Tab, Ctrl+PageDown | Ctrl+Tab, Ctrl+PageDown |
| Previous tab | Ctrl+Shift+Tab, Ctrl+PageUp | Ctrl+Shift+Tab, Ctrl+PageUp |
| Go to tab 1 to 8 | Ctrl+1 to Ctrl+8 | Cmd+1 to Cmd+8 |
| Go to the last tab | Ctrl+9 | Cmd+9 |
| Go to the next dashboard | Ctrl+Shift+D | Cmd+Shift+D |

### Repository

| Action | Windows and Linux | macOS |
|---|---|---|
| Fetch all remotes | Ctrl+Shift+F | Cmd+Shift+F |
| Pull | Ctrl+Shift+L | Cmd+Shift+L |
| Push | Ctrl+Shift+K | Cmd+Shift+K |
| Create branch… | Ctrl+B | Cmd+B |
| Stash changes… | Ctrl+Shift+S | Cmd+Shift+S |
| Pop the newest stash | Ctrl+Shift+O | Cmd+Shift+O |
| Undo | Ctrl+Z | Cmd+Z |
| Redo | Ctrl+Y, Ctrl+Shift+Z | Cmd+Shift+Z, Cmd+Y |
| Search commits | Ctrl+F | Cmd+F |
| Next match | F3, Ctrl+G | Cmd+G, F3 |
| Previous match | Shift+F3, Ctrl+Shift+G | Cmd+Shift+G, Shift+F3 |
| Show reflog | Ctrl+Shift+R | Cmd+Shift+R |

On a dashboard, Fetch and Pull fetch and pull every repository of its workspace.

### Moving around

| Action | Windows and Linux | macOS |
|---|---|---|
| Filter branches and tags | Ctrl+Shift+E | Cmd+Shift+E |
| Next region | F6 | F6 |
| Previous region | Shift+F6 | Shift+F6 |
| Context menu | Shift+F10, Menu | Shift+F10 |
| Move in the graph | Up, Down, PageUp, PageDown, Home, End | Up, Down, PageUp, PageDown, Home, End |
| Extend the graph's selection | Shift+Up, Shift+Down, Shift+PageUp, Shift+PageDown, Shift+Home, Shift+End | Shift+Up, Shift+Down, Shift+PageUp, Shift+PageDown, Shift+Home, Shift+End |

macOS: On a Mac keyboard F6, Shift+F6 and Shift+F10 need Fn unless "Use F1, F2, etc. keys as standard function keys" is on; Home, End, PageUp and PageDown are Fn with the arrows.
