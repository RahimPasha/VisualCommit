# About VisualCommit

## The About section

Settings' **About** section shows VisualCommit's name and icon, who created it, its version and the
commit it was built from, the copyright line, its license, the third-party notices, and links to
its source code and to this guide. Open it with **Settings** in the toolbar, then **About**, or
with **About VisualCommit…** in the command palette. On macOS it is also in the application menu,
as **About VisualCommit**.

- **Version**: the version number, and in parentheses the first seven characters of the commit the
  build was made from. Give both when you report a problem.
- **License**: VisualCommit is released under the **MIT License**. **Show license…** shows its
  text, with **Copy all**.
- **Notices**: "VisualCommit is built on open-source components, each under its own license."
  **Show third-party notices…** shows the components, their licenses, and the notice files their
  makers ship.
- **Source code** opens the repository,
  [github.com/RahimPasha/VisualCommit](https://github.com/RahimPasha/VisualCommit), in your browser.
- **User guide**: **Open the user guide** opens this guide. F1 opens it too, but not while the
  settings screen, the command palette, another dialog or a menu is open, or while you drag a
  branch: from here, use the link.
